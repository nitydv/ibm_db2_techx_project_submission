# ResQNet AI – Intelligent Emergency Response Network

## Project Overview

ResQNet AI is an emergency response platform designed to help people report emergencies and support faster response coordination.

## Key Features

* Emergency incident reporting
* Real-time command center dashboard
* Emergency location mapping
* Responder management
* Analytics and monitoring
* Women Safety Center
* Anonymous crime reporting

## Technology Stack

* Python
* Flask
* MySQL
* IBM Db2
* HTML, CSS and JavaScript

## Database Integration

MySQL is used as the primary database, with IBM Db2 providing additional incident data synchronization.
