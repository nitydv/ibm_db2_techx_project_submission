# ResQNet AI – Intelligent Emergency Response Network

## Project Overview

ResQNet AI is an intelligent emergency response platform designed to improve emergency reporting, monitoring, and coordination.

The platform helps users report emergencies and enables administrators to monitor incidents through a centralized command center.

## Problem Statement

Traditional emergency reporting systems often face delays, poor coordination, and a lack of real-time incident monitoring.

## Proposed Solution

ResQNet AI provides:

* Emergency Reporting System
* AI-Based Incident Analysis
* Real-Time Command Center Dashboard
* Emergency Location Mapping
* Responder Management
* Women Safety Center
* Anonymous Crime Reporting
* MySQL and IBM Db2 Database Integration

## Technology Stack

* Python
* Flask
* HTML, CSS, JavaScript
* MySQL
* IBM Db2
* IBM Db2 Python Driver (ibm_db)

## IBM Db2 Integration

ResQNet AI uses IBM Db2 as an additional database for storing emergency incident records.

When a new emergency report is submitted, the application saves the record in MySQL and synchronizes it with IBM Db2.

## Installation

1. Clone the repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Configure database credentials in `.env`.
4. Start the Flask application using `python app.py`.
